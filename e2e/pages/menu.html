Menu Navigation

Keyboard-driven menu with roving tabindex, type-ahead search, and WAI-ARIA compliance. Open a menu, then use arrow keys, Home/End, Enter/Space, or type a character.

Vertical menu (default)

Arrow Up/Down to navigate. Cherry is disabled, Date is aria-disabled: both are skipped. Type a letter to jump to a matching item.

Horizontal menu

Arrow Left/Right to navigate instead of Up/Down.

No-loop menu

Navigation clamps at the first and last item instead of wrapping around.

Type-ahead disabled

Typing characters has no effect.

Custom selector

Uses .nav-item divs instead of [role="menuitem"] buttons.
