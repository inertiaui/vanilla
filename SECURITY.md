# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

Please report security vulnerabilities privately via [GitHub Security Advisories](https://github.com/inertiaui/vanilla/security/advisories/new) or email `pascal@protone.media`.

Do not open public GitHub issues for security reports.

Expect an initial response within 72 hours. Once confirmed, a fix and coordinated disclosure timeline will follow.
